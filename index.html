Pandas

Manipulación Avanzada de DataFrames

Pandas es la biblioteca fundamental para análisis de datos en Python. Descubre técnicas avanzadas directamente de la documentación oficial.

Indexación Eficiente

El poder real de Pandas reside en sus múltiples métodos de indexación:

  • .loc[] - Indexación basada en etiquetas, ideal para selecciones explícitas y legibles
  • .iloc[] - Indexación basada en posición entera, perfecta para operaciones numéricas
  • .at[] y .iat[] - Acceso ultra-rápido a valores escalares individuales
# Técnicas de indexación avanzada
import pandas as pd

# Crear DataFrame de ejemplo
df = pd.DataFrame({
    'nombre': ['Ana', 'Bruno', 'Carlos'],
    'edad': [25, 30, 35],
    'ciudad': ['Madrid', 'Barcelona', 'Valencia']
}, index=['a', 'b', 'c'])

# Selección por etiqueta
resultado = df.loc['a':'b', 'nombre':'edad']

# Selección por posición
resultado = df.iloc[0:2, 0:2]

💡 Consejo de Rendimiento

Según la documentación oficial, usar .at[] en lugar de .loc[] para acceder a valores escalares individuales puede ser hasta 100 veces más rápido en DataFrames grandes.

GroupBy: El Poder de la Agregación

El método GroupBy permite la estrategia "split-apply-combine" documentada exhaustivamente en Pandas:

# Agregaciones múltiples con agg()
resultado = df.groupby('categoria').agg({
    'ventas': ['sum', 'mean', 'std'],
    'clientes': 'count',
    'precio': ['min', 'max']
})

# Transformaciones personalizadas
df['zscore'] = df.groupby('grupo')['valor'].transform(
    lambda x: (x - x.mean()) / x.std()
)
NumPy

Computación Numérica de Alto Rendimiento

NumPy es el núcleo de la computación científica en Python, proporcionando arrays multidimensionales y operaciones matemáticas ultra-rápidas.

Broadcasting: Magia de Arrays

El broadcasting es una de las características más poderosas de NumPy, permitiendo operaciones entre arrays de diferentes formas:

import numpy as np

# Broadcasting básico
a = np.array([[1, 2, 3],
              [4, 5, 6]])

# Suma con escalar (broadcasting automático)
resultado = a + 10  # [[11, 12, 13], [14, 15, 16]]

# Broadcasting con array 1D
b = np.array([10, 20, 30])
resultado = a + b  # [[11, 22, 33], [14, 25, 36]]

# Normalización por columnas (patrón común)
media = a.mean(axis=0)
std = a.std(axis=0)
normalizado = (a - media) / std

⚡ Optimización Crítica

La documentación de NumPy enfatiza: las operaciones vectorizadas son 10-100x más rápidas que los bucles Python equivalentes. Siempre busca eliminar bucles explícitos usando broadcasting y funciones universales (ufuncs).

Indexación Avanzada y Fancy Indexing

# Fancy indexing con arrays booleanos
datos = np.random.randn(100)
outliers = datos[np.abs(datos) > 2]

# Indexación con arrays de enteros
indices = np.array([0, 2, 4])
seleccion = datos[indices]

# Combinación poderosa: where
resultado = np.where(datos > 0, datos, 0)  # ReLU
  • Álgebra Lineal - Módulo linalg para operaciones matriciales eficientes
  • FFT - Transformada rápida de Fourier optimizada
  • Random - Generación de números aleatorios de alta calidad
  • Structured Arrays - Arrays con campos nombrados tipo registro
Matplotlib

Visualización Científica Profesional

Matplotlib es la biblioteca de visualización más completa de Python, con dos interfaces principales: pyplot (estilo MATLAB) y orientada a objetos.

API Orientada a Objetos vs pyplot

La documentación oficial recomienda fuertemente la API orientada a objetos para mayor control y flexibilidad:

import matplotlib.pyplot as plt

# Estilo Orientado a Objetos (RECOMENDADO)
fig, ax = plt.subplots(figsize=(10, 6))

ax.plot(x, y, label='Datos', linewidth=2, color='#2E86AB')
ax.set_xlabel('Tiempo (s)', fontsize=12)
ax.set_ylabel('Amplitud', fontsize=12)
ax.set_title('Análisis Temporal', fontsize=14, fontweight='bold')
ax.grid(True, alpha=0.3)
ax.legend(frameon=False)

# Subplots complejos
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(15, 5))
ax1.scatter(x, y1, alpha=0.6)
ax2.bar(categorias, valores)

🎨 Estilo y Estética

Matplotlib incluye estilos predefinidos profesionales. Usa plt.style.use('seaborn-v0_8-darkgrid') o crea tu propio estilo con rcParams para gráficos consistentes y publicables.

Personalización Avanzada

# Configuración global con rcParams
plt.rcParams.update({
    'font.size': 11,
    'font.family': 'serif',
    'axes.labelsize': 12,
    'axes.titlesize': 14,
    'figure.dpi': 100,
    'savefig.dpi': 300
})

# Anotaciones y flechas
ax.annotate('Punto crítico', 
            xy=(5, 10),
            xytext=(6, 12),
            arrowprops=dict(arrowstyle='->', color='red'))
  • Colormaps - Paletas científicas (viridis, plasma) para datos continuos
  • 3D Plots - Visualizaciones tridimensionales con mplot3d
  • Animaciones - Módulo animation para visualizaciones dinámicas
  • Backends - Múltiples opciones de renderizado (Agg, TkAgg, Qt5Agg)
Seaborn

Visualización Estadística Elegante

Seaborn eleva Matplotlib con una API de alto nivel, estilos hermosos por defecto y funcionalidad estadística integrada.

Gráficos Relacionales y Distribuciones

import seaborn as sns
import matplotlib.pyplot as plt

# Configurar tema elegante
sns.set_theme(style='whitegrid', palette='deep')

# Scatter plot con regresión automática
sns.lmplot(data=df, x='peso', y='altura', 
           hue='genero', height=6)

# Distribuciones con histograma y KDE
sns.histplot(data=df, x='edad', kde=True, 
            bins=30, color='#E63946')

# Violin plot para comparaciones
sns.violinplot(data=df, x='categoria', y='valor',
               split=True, inner='quartile')

FacetGrid: Visualizaciones Múltiples

Una de las características más poderosas documentadas en Seaborn es FacetGrid para crear matrices de gráficos condicionados:

# Crear grid de subplots automático
g = sns.FacetGrid(df, col='mes', row='año', 
                  height=3, aspect=1.2)

g.map(sns.scatterplot, 'x', 'y', alpha=0.7)
g.add_legend()

# PairGrid para relaciones multivariadas
g = sns.PairGrid(df, vars=['var1', 'var2', 'var3'])
g.map_diag(sns.histplot)
g.map_offdiag(sns.scatterplot)

📊 Paletas de Color Profesionales

Seaborn proporciona paletas científicamente diseñadas: usa paletas cualitativas como 'Set2' o 'tab10' para categorías, secuenciales como 'Blues' o 'YlOrRd' para datos continuos, y divergentes como 'RdBu' para datos que divergen desde un punto central.

Heatmaps y Matrices

# Matriz de correlación profesional
corr = df.corr()
sns.heatmap(corr, annot=True, cmap='coolwarm',
            center=0, square=True,
            linewidths=1, cbar_kws={'shrink': 0.8})

# Clustermap con jerarquía
sns.clustermap(df, method='ward', 
               cmap='viridis', figsize=(12, 10))
  • Categorical plots - boxplot, violinplot, swarmplot para datos categóricos
  • Regression plots - regplot y lmplot con intervalos de confianza
  • Themes - darkgrid, whitegrid, dark, white, ticks
  • Color palettes - Integración con ColorBrewer y paletas perceptualmente uniformes
